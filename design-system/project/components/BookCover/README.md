# BookCover

Three A4 front-cover layouts for Quantum IAS & PCS books: Flagship (navy), Source Book (cream) and Test Series (cream with navy head and red band).

**The consumer provides:** title (English), Hindi title, one subtitle line, the exam tag ("UPPSC Prelims 2026"), and for Test Series the test code, paper name, question count, marks and duration. The crest always comes from `assets/Logos/quantum-crest.png`.

**Choose the layout by product**
- Flagship: printed subject books, full-course sets, anything sold as a physical book.
- Source Book: TATTVA and PYQ concept-note PDFs; matches the locked TATTVA inside-page style.
- Test Series: mock test booklets and answer-key books.

**Do**
- Keep titles to two lines at `cover-title`; shorten rather than shrink below 28px (at 300px width).
- Use real numbers only on covers.
- Export print files at 2480 × 3508 px (300 dpi) with 3mm bleed on navy grounds.

**Don't**
- Don't put photos, icons or illustrations on covers; the crest is the only image.
- Don't use more than one red element per cover.
- Don't set the crest on navy without its gold halo.
