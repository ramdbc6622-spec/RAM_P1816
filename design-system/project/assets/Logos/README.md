# Logos

- `quantum-crest.png`: the official crest, 1024 × 1024 px, transparent outside the circle. Colours: navy `#1e3352`, gold `#a68d5e`, red `#a62e34`, on a cream `#fbf5eb` field. Use on `cream` directly, on `navy` inside a `gold` halo. Minimum 46px on screen, 25mm in print.
- There is no vector version yet; for large print (above A4), request an SVG redraw of the crest from the designer rather than upscaling.
